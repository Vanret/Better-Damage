# Better Damage
A Minecraft Forge 1.20.1 mod that completely overhauls the game’s damage system. It introduces new damage aspects, defense and damage modifiers, as well as new mechanics and gameplay features.
It features flexible integration thanks to operating entirely on entity NBT tags. Damage itself is divided into aspects using standard in-game tags.
A separate section list the damage tags and NBT data that the mod use in the final calculations.
